\caption{\textbf{The audit in tensor-network terms.} Any trained variational model is a matrix
product state whose bond dimension caps the entanglement it carries \citep{shin2024}.
\textbf{(1)} We write the trained state $|\psi_\theta(x)\rangle$ as an MPS, with orange physical
legs $q_i$ and blue bond legs. \textbf{(2)} For each bond we keep only the largest $\chi$ singular
values and discard the rest, the standard MPS truncation. \textbf{(3)} \textsc{SimCert} contracts
the $\chi$-capped MPS with the red readout observables and asks how small $\chi$ can be before the
recovered prediction $\hat y^{(\chi)}$ changes. For every audited model the answer is $\chi{=}1$, a
product state, or $\chi{=}2$, whereas an exact representation would need bond dimension
$2^{\lfloor n/2\rfloor}$.}
